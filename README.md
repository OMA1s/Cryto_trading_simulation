# Cryto_trading_simulation

This project is part of Coursera's Object Oriented Programming specialization by University of London.
This is a C++ console program that simulates a crypto trading platform. The user starts with 10 BTC. They have options to make an offer, or make a bid.
Other bids/asks are loaded from a csv file into the program.

Future works: Planning to add GUI into the program using ImGui
